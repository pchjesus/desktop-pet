Desktop Pet 사용 설명서

1. 시작과 캐릭터 선택

시작 화면에서 늑구·가디·로이스·대굴레오·파치리스 중 하나를 선택한 뒤 시작을 누릅니다. 설명서는 시작 화면의 설명서 버튼으로 열 수 있습니다.

펫은 바탕화면에서 스스로 걷고, 쉬고, 앉거나 잠듭니다. 바라보는 방향은 이동 방향에 맞춰 바뀝니다.

2. 클릭·드래그·홈 복귀

  • 좌클릭: 캐릭터 반응과 말풍선을 표시합니다.
  • 드래그: 펫을 원하는 위치나 연결된 다른 모니터로 옮깁니다.
  • 우클릭: Windows 기본 선택창에서 아래 동작을 선택합니다.
선택동작
홈으로현재 펫을 닫고 시작 화면으로 돌아갑니다.
종료앱을 완전히 종료합니다.
취소현재 펫을 계속 실행합니다.

캐릭터 전환: 펫 우클릭 → 홈으로 → 다른 캐릭터 선택 → 시작 순서로 바꿉니다. 홈으로 돌아가면 진행 중인 모션과 입력은 끝나고, 다음 캐릭터는 새로 시작합니다.

3. 특수 코드 입력

먼저 해당 펫을 클릭한 뒤 5초 안에 영문 코드와 Enter를 입력합니다. 대소문자는 구분하지 않으며 Backspace로 고칠 수 있습니다. 잘못 입력했다면 Enter 후 다시 입력하거나 펫을 다시 클릭합니다.

캐릭터코드와 동작
가디Flamethrower: 화염방사
pocketmon: 팬 프로젝트 창
파치리스FollowMe: 날따름·용성군·열매 먹기
대굴레오watergun: 물대포
icebeam: 냉동빔
pocketmon: 팬 프로젝트 창

4. 캐릭터별 행동

늑구·로이스

둥근 강아지 외형으로 호흡·꼬리 움직임·걷기·앉기·잠자기·클릭 반응·드래그 자세를 보여줍니다. 로이스는 검정·황갈색 무늬와 별도의 클릭 말풍선을 가집니다.

가디

원본 도트 스타일의 걷기와 클릭 반응을 유지하며, 호흡·귀·꼬리와 앉기·드래그 자세를 보여줍니다. 잠들면 옆으로 몸을 모으고 얼굴을 앞발 쪽에 기대며 작게 호흡하고, 깨어날 때 머리와 몸을 순서대로 일으킵니다.

화염방사는 준비·점화 → 입에 이어진 연속 화염 → 잦아들기 → 정상 복귀로 재생됩니다. 진행 중 중복 입력은 무시하며, 실제 드래그로 취소할 수 있습니다.

파치리스

일반 클릭에는 짧은 전기 반응이 나옵니다. FollowMe에서는 머리 위 손가락 아이콘이 나타나고, 용성군이 뒤쪽에서 오른쪽 위 → 왼쪽 아래로 떨어집니다. 앞발에 든 자뭉열매는 전체 → 일부 먹힘 → 대부분 먹힘 → 소멸 단계를 거쳐 회복 후 돌아옵니다.

FollowMe는 약 4.4초 동안 재생됩니다. 중복 입력으로 다시 시작하지 않으며, 실제 드래그로 취소할 수 있습니다.

대굴레오

이동할 때 몸을 말아 구르는 ROLL을 사용합니다. 클릭하면 CLAP 박수를 치며, 쉬는 중에도 간헐적으로 박수칩니다. CLAP을 위한 별도 입력 코드는 없습니다.

WATER GUN은 물줄기 발사 후 물을 털고 돌아옵니다. ICE BEAM은 냉동빔 → 약 1초 동결 → 얼음 파쇄 → 정상 복귀 순서입니다. 진행 중 일반 이동이 끼어들지 않으며 같은 특수모션을 중복 실행하지 않습니다.

5. 모니터·화면 경계

펫 본체가 작업 영역에서 완전히 사라지지 않도록 위치를 보정합니다. 드래그로 연결된 다른 모니터로 옮길 수 있습니다. 모니터 연결·해제, 해상도 또는 작업표시줄 위치 변경 시에도 위치와 이동 범위를 갱신합니다.

Windows 배율과 모니터 배치에 따라 가장자리 표시가 달라질 수 있습니다. 화면을 바꾼 뒤 위치·드래그가 자연스러운지 확인해 주세요. 특수 효과의 끝이나 말풍선이 본체와 같은 범위까지 보장되는 것은 아닙니다.

펫은 다른 창 위에 표시됩니다. 투명한 부분은 마우스 입력이 통과할 수 있습니다.

6. 종료·문의

일반 종료는 펫 우클릭 → 종료를 사용합니다. 응답이 없을 때만 Windows 작업 관리자에서 Desktop Pet 프로세스를 종료합니다.

문제 제보 시 캐릭터, 입력 순서, Windows 배율·모니터 배치와 화면을 함께 알려주세요.
