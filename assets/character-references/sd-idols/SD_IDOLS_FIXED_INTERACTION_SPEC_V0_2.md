# SD 아이돌 펫 — 고정형 상호작용 및 캐릭터성 명세 v0.2

작성: 2026-11-03  
상태: **사용자 확정 방향 반영 / 동작 수치·애니메이션 프레임은 미승인**  
이 문서는 이전 `MOTION_SPEC_DRAFT_V0_1.md`의 **자율 이동·WALK 중심 제안 및 지우의 활발한 인사 성격**을 대체한다.

## 1. 승인 외형과 기준 이미지

- 기준: 2026-11-03 사용자가 다시 첨부한 **3인 합본 이미지(대화 업로드 `1000040935.png`)**. 이 합본의 왼쪽 지우, 중앙 설윤, 오른쪽 세은을 시각적 기준으로 사용한다.
- 지우: 기존 **v1 승인**. v1.1 헤어라인 변경은 **명시적 미채택**. 이미지 재생성으로 표정/얼굴/키/복장/포즈를 바꾸지 않는다.
- 설윤·세은: 기존 1차 승인본 고정, 재생성 금지.
- GitHub에는 해시와 승인 기록은 있지만 PNG 바이너리는 별도 대화 백업에 있다. 프로토타입 제작 전 **가장 최근 업로드 이미지와 승인 기록의 실제 바이트/해시를 비교 검증**해야 한다. 다른 크롭이나 이전 결과를 조용히 대체하지 않는다.
- 이 내용은 아이돌 실제 인성 평가가 아니라 **SD 펫의 창작 캐릭터성**이다.

## 2. 사용자 확정 UX

- **자동 자율 이동 없음.** 기존 기존 펫 5종의 자율 이동 동작은 유지하고, 신규 아이돌 3인에만 적용한다.
- 아이돌 펫은 화면의 정해진 위치에서 머문다. 위치 변경은 사용자가 **드래그**할 때만 발생한다.
- 평상시: 짧은 눈 깜빡임과 미세 움직임, 때때로 짧은 말풍선 및 특정 자율 행동.
- 클릭: 캐릭터별 표정/동작과 짧은 대사. 1회 반응 후 기본 상태 복귀.
- 향후 ChatGPT 연동: 답변 도착, 작업 완료 등 **이벤트를 수신할 수 있는 연결 방식이 마련된 경우에만** 알림. ChatGPT 앱 내부 이벤트를 현재 직접 수신할 수 있다고 가정하지 않는다.
- 외형만 가리는 새 GUI, 위치 이동, 세 명 동시 실행, 글로벌 행동 엔진 변경은 별도 승인 필요.

## 3. 캐릭터 성격 — 최신 사용자 결정

| 캐릭터 | 기본 | 드문 반전 | 동작/말풍선 연출 | 과장 금지 |
| --- | --- | --- | --- | --- |
| **지우** | **셋 중 가장 차분함**. 시크·도도한 냉미녀 분위기 | 은근하게 장난치기/살짝 놀리기 | 작은 고개 기울임, 눈매 변화, 절제된 짧은 말풍선. 장난은 가끔만 | 기본을 '활발하고 애교 많은 인사형'으로 만들지 않음. 이미 승인된 손 흔드는 정적 포즈는 임의 변경 금지 |
| **설윤** | 기존의 온화하고 다정하며 차분한 이미지 | **가끔 예상 밖의 엉뚱한 반응** | 부드러운 고개 움직임, 짧은 배려의 말, 드물게 뜬금없는 한마디/작은 엉뚱한 동작 | 항상 엉뚱하거나 산만한 캐릭터로 만들지 않음. 기존 모은 손 포즈 보존 |
| **세은** | 기존의 귀엽고 발랄한 장난기 | 기존 반응 방향 유지 | 상대적으로 가볍고 활발한 클릭 반응과 말풍선 | 사용자가 바꾸지 않은 성격을 임의로 재정의하지 않음. 기존 손가락/단발/장식 포즈 보존 |

### 대사 톤 예시 (사용자 확인 전 예문이며 실제 인물 발언 아님)

- 지우: 평소 "응, 보고 있어.", "수고했네." / 가끔 장난 "나 보고 있었지?"
- 설윤: 평소 "오늘도 수고했어요.", "천천히 해도 괜찮아요." / 가끔 엉뚱하게 "갑자기 붕어빵 생각났어요."
- 세은: "또 왔어? ㅎㅎ", "심심하지?", "나랑 놀아줘!"

대사 후보는 캐릭터의 **고유 명대사나 실제 발언이라고 표기하지 않는다**. 클릭 반응/자발 행동의 빈도는 **성격상 상대적 차이**만 정의하고, 초 단위 타이밍·확률은 시각 프로토타입 검토 뒤 결정한다.

## 4. 상태/이벤트 방향 (신규 SD 3인 전용)

- `IDLE`: 화면 고정, 기본 외형 보존.
- `BLINK`: 짧은 눈 깜빡임. 공통 엔진 상태가 아닌 시각적 서브모션으로 우선 검토.
- `TALK`: 말풍선과 짧은 입/표정 변화(승인된 얼굴을 흔들지 않음).
- `REACT`: 클릭 1회에 맞춘 행동. 필요시 `SPECIAL`: 드물게 등장하는 캐릭터 전용 짧은 행동.
- `DRAG`: 기존 펫과 동일하게 사용자가 잡고 옮기기, 놓은 뒤 원래 고정형 IDLE 복귀.
- `NOTIFY`: 향후 외부 이벤트를 실제 수신했을 때에만 말풍선/알림 발생. 현재 구현 완료로 표시하지 않음.
- 우선순위 후보: DRAG > 직접 클릭 > 수신한 알림 > 자발적 특수 행동 > 기본 IDLE. 이벤트 큐/중첩 규칙은 구현 전에 정한다.
- `WALK` 자율 이동은 **아이돌 3인에게 사용하지 않음**. 기존 펫 전역에서 삭제/비활성화하는 것은 금지.
- `SIT/SLEEP`은 이번 사용자 결정에 포함되지 않았으므로 자동 구현하지 않는다.

## 5. 직전 IDLE 시험작 문제와 수정 조건

이전 `JIWOO_IDLE_PROTOTYPE_V0_1.md`의 지우 눈 감기 프레임에서 **눈동자/눈 하이라이트가 비쳐 보이는 결함**을 사용자가 지적했다.

- 눈동자와 하이라이트를 닫힌 프레임에서 완전히 가리고, **원본 눈 레이어를 충분한 범위로 덮는 완전 불투명한 피부/눈꺼풀 픽셀**을 만든다.
- 단순히 기존 눈 위에 반투명 눈꺼풀을 덧씌우는 방식 금지. 실제 렌더 이미지에서 눈동자 잔상/알파 문제가 없는지 확인.
- 기준 합본 `1000040935.png`의 왼쪽 지우를 바탕으로 사용한다. 이전의 원본과 유사하지만 다른 크롭/재생성 결과를 섞지 않는다.
- 수정된 후보는 승인 v1을 덮어쓰지 않는다. 눈 뜬 원본/눈 감은 프레임/복귀 프레임의 픽셀 및 가장자리 변화를 확대 비교한다.
- 먼저 정지 프레임으로 충분히 확인한 다음 실제 프레임 애니메이션을 만들고, 마지막으로 사용자 시각 검토를 받는다.

## 6. 향후 ChatGPT 연동 구상 (미구현)

- 알림 유형 후보: `response-ready`, `task-completed` 등. **실제 이용 가능한 공식 연동 인터페이스/권한/이벤트 출처를 조사한 뒤** 구현 범위 결정.
- 개인 대화 내용의 자동 상시 수집이나 무단 표시를 가정하지 않는다. 민감 정보가 포함될 수 있으므로 기본 알림은 일반 메시지(예: "답변이 도착했어")로 제한하는 방향을 우선 검토한다.
- Electron 알림/말풍선의 포커스, 투명 창 클릭 통과, 위치, 종료 처리와 호환성을 별도 검증한다.
- 독립적으로 구현 가능한 로컬 이벤트(예: 앱 자체 작업 완료)와 ChatGPT 서비스 내부 완료 이벤트를 구별한다.

## 7. 변경 경계·현황

- 이번 문서는 **설계 기록만 추가**. `main`, 기존 승인 PNG, `src/pet-engine.js`, `src/renderer.js`, `src/main.js`, 창 동작/IPC/기존 펫 5종을 수정하지 않는다.
- 실제 눈 감은 프레임 수정, 움직이는 프로토타입, Electron 실행/EXE 검증, ChatGPT 연결은 **미실행/미검증**.
- 다음 작업은 정확한 승인 합본을 소스로 검증하고 **지우 눈 감기 프레임의 비침 문제부터** 국소 재제작하는 것이다.
