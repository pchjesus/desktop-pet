# SD 아이돌 3인 — IDLE 눈 깜빡임 시연 v0.3

작성: 2026-11-03 KST  
상태: **미승인, 정적 승인 외형 보호 / Electron 미통합**

## 기준 이미지·상태

- 사용자 재첨부 3인 승인 합본 `1000040935.png`: **1536 × 865 RGB, 검은 배경**. 이 파일의 픽셀을 그대로 사용.
- SHA-256: `3c1626ac3fcc3e78c289f96ff6106b84f235ae2c47f9c1aaa9d5193e04c30d3f`.
- **지우 정적 v1 승인 유지**, 지우 헤어라인 v1.1 미채택. 지우 IDLE 눈 v0.2는 사용자가 "괜찮은 듯"이라고 평한 *시안*으로, 완전한 애니메이션 승인으로 간주하지 않는다.
- 설윤·세은 정적 승인 디자인 및 원본 보호. 새 닫힌 눈 애니메이션은 별도 **미승인 후보**다.
- 승인된 3인 원본을 다시 생성하지 않았고, 별도 크롭으로 원본을 대체하지 않았다.

## 이번에 실제 제작한 것

1. **설윤**: 원본 눈동자·하이라이트를 완전 불투명한 피부색 픽셀로 대체하고 부드러운 곡선의 감긴 눈꺼풀을 별도 제작.
2. **세은**: 같은 원리로 원래의 눈꼬리·귀 주변 윤곽을 고려한 별도의 눈꺼풀 프레임 제작. 아이 메이크업과 귀/머리카락 경계의 잔상을 점검하고 수정.
3. **3인 시차 미리보기**: 지우의 이전 v0.2 시험 닫힌 눈을 재사용. 3인이 각자 다른 순간에 눈을 깜빡이는 **8초 루프(11프레임)**. 자율 이동/위치 이동 없음.
4. 설윤과 세은 각각 별도의 8초 애니메이션 프리뷰 생성. 눈 깜빡임 외의 행동은 구현하지 않음.

## 실제 픽셀 검증

| 눈 감은 프레임 | 변경 픽셀 | 변경 bbox (inclusive: x0,y0,x1,y1) | 다른 캐릭터 픽셀 |
|---|---:|---|---|
| 지우 (기존 v0.2) | 12,724 | (169,252,390,341) | 0 |
| 설윤 (신규) | 9,428 | (695,260,899,341) | 0 |
| 세은 (신규) | 9,789 | (1155,268,1389,342) | 0 |

- **모든 프리뷰의 열린 눈 프레임은 사용자가 올린 원본 합본과 RGB 픽셀이 완전히 같다.**
- 모든 닫힌 눈 프레임의 변경 픽셀은 각 사람의 눈 주변 지정 범위 내에 한정.
- 정적 원본 파일의 바이트는 수정되지 않았음. 설윤·세은의 의상, 신체, 포즈 및 나머지 사람의 얼굴 변경 없음.
- 원본 화질 lossless APNG / WebP의 **전 프레임을 디코딩해 예상 RGB 프레임과 일치**하는지 확인.
- GIF는 용량과 범용 미리보기를 위해 축소/팔레트 양자화를 적용했으므로, GIF의 색상값을 승인 원본과 비트 단위로 비교해서는 안 됨.
- 사용자용 ZIP CRC 테스트 통과.
