# 지우 IDLE 기본 정지 프레임 — 국소 수정 명세 v0.1

작성: 2026-11-04 (KST)  
상태: **디자인 제작 지시 초안 / 미승인 / 이미지·Electron 변경 없음**

## 1. 원본 및 범위

- **절대 기준**: 사용자가 재지정한 3인 이미지 `1000040935.png`, 1536×865 RGB, 검은 배경.
- **실제 파일 SHA-256 확인**: `3c1626ac3fcc3e78c289f96ff6106b84f235ae2c47f9c1aaa9d5193e04c30d3f`.
- 그중 **왼쪽 Hearts2Hearts 지우만** 신규 IDLE 후보 제작 대상으로 삼는다. 중앙 설윤·오른쪽 세은은 원본 이미지의 **픽셀 하나도 바꾸지 않는다**.
- 이 파일은 기준 일러스트이며, 후보가 승인되지 않는 한 원래 지우 v1 승인본(손을 들고 입 벌려 웃는 포즈)을 대체하지 않는다.
- 기존 지우 v1.1 헤어라인 수정 및 이전 눈꺼풀 덧그리기 프레임은 채택하지 않는다.
- 산출물은 **IDLE 기본 정지 프레임 후보** 1장과 눈·입·팔 수정 영역의 나란히 비교본; GIF/스프라이트/앱 통합은 이 단계에 포함하지 않는다.

## 2. 얼굴: 눈·눈썹·입

| 부위 | 현재 승인 기준 | 신규 IDLE 후보 (변경 허용) | 금지 |
|---|---|---|---|
| 눈 | 두 눈 모두 뜨고 정면을 바라보는 갈색 홍채와 속눈썹 | **열린 눈의 크기·위치·디테일은 거의 그대로 유지**; 억지로 반쯤 감긴 냉한 눈으로 만들지 않는다 | 눈을 확대/축소하거나 다른 아이돌식 눈매로 대체 |
| 눈썹 | 완만한 자연 눈썹 | 원래 각도·위치를 유지해 차분한 인상 | 과도하게 찡그리거나 눈썹을 치켜올림 |
| 입 | 입 벌린 밝은 웃음 | **입 다문 짧고 부드러운 입선**, 끝은 아주 약하게 올라간 수준. 무표정과 절제된 미소 사이 | 무뚝뚝한 일자 표정, 찡그림, 과한 애교 |
| 볼·얼굴형 | 밝은 볼과 매끄러운 턱선 | 원래 피부/볼륨/하이라이트/턱선 유지 | 턱을 뾰족하게 재설계하거나 볼터치 확대 |

- 사용자 표현인 '냉미녀, 차분하고 도도하며 가끔 장난'은 **표정의 절제와 행동 빈도**로 전달한다. 기존 지우의 얼굴 인식 특징은 그대로 유지한다.

## 3. 머리·옷·비율

- 현 승인 그림의 짙은 단발, 가르마, 앞머리 가닥, 귀, 펄 드롭 귀걸이, 목걸이, 상의의 파란색/흰 줄무늬, 검은 벨트, 흰 플리츠스커트, 하얀 양말/운동화, 다리 간격은 그대로 보존.
- 머리 크기, 얼굴 세로·가로 비율, 눈 사이 거리, 키/신체 비율, 위치, 발 접지점은 **동일**.
- 머리카락 전체 재생성 금지. 팔 변경으로 가려졌다 드러나는 소매/옆구리 등 필요한 작은 영역만 원본에 맞게 보완.
- 현재 검은색 배경이 있는 RGB 이미지를 투명 PNG라고 주장하지 않는다. 투명도 추출은 별도 작업.

## 4. 포즈: 인사하는 상태에서 가만히 서 있는 상태로

- 지금 들어 올린 **지우 오른손(화면 왼쪽)** 을 내려서 옆구리/스커트 옆에 자연스럽게 둔다.
- 다른 팔(화면 오른쪽)은 기존처럼 자연스럽게 내린 형태를 최대한 유지한다.
- **두 손을 앞에서 모으지 않는다.** 지나치게 수줍거나 공손한 성격으로 읽히기 때문.
- 손가락은 가볍게 이완한 형태로, 주먹 쥠·새 V 포즈·주먹질·손 흔들기 금지.
- 어깨는 수평에 가까운 편안한 자세, 몸 중심과 신발의 접지는 원본과 동일. 과한 한쪽 체중 싣기/고개 기울임 금지.
- 기존 손 흔드는 포즈는 향후 **클릭 REACT 참고 포즈**로 보관한다.

## 5. 눈 깜빡임은 IDLE 기본 정지 프레임 승인 이후

- **정지 프레임이 승인되기 전에는** 눈 감은 상태를 만들지 않는다.
- 이후 눈 뜸 → 반감김 → 완전 감김 → 반열림 → 눈 뜸의 연속성을 눈 구조에 맞춰 제작한다.
- 눈동자 위에 피부색을 어설프게 반투명 덧칠하지 않는다. 기존 눈 구조를 완전히 대체한, 새로운 닫힌 눈 그림을 **같은 얼굴 좌표와 크기**로 그린다. 눈/속눈썹/눈꺼풀과 눈썹 사이 해부학적 연결 유지.
- 원본 기준 눈의 너비/좌표와 눈꺼풀 프레임을 확대 비교하고, 투명도 잔상/부정확한 크기/경계 자국이 있으면 반려한다.

## 6. 프로토타입 승인 기준

1. SD 캐릭터가 **얼굴과 머리만 봐도 기존 승인 지우와 같은 인물로 읽힘**.
2. 입은 닫혀 있고 표정은 조용하면서 약하게 웃음.
3. 팔은 편히 내려와 있으며 인사하거나 반응 중인 포즈가 아님.
4. 원본에서 합의한 옷·액세서리·머리·신체 비율과 같은 형태임.
5. **설윤·세은 원본 변경 픽셀 0개**. 합성본에서 검증할 것.
6. 원본 PNG, 새 후보 PNG, 좌우 비교 확대본 및 실제 픽셀 변경 범위·SHA-256 보고.
7. 시안이 마음에 들지 않으면 기존 승인본 그대로 롤백. 사용자 승인 전 **v1 교체 금지**.
