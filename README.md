# Desktop Pet

화면 위를 자유롭게 돌아다니며 다양한 행동을 하는 데스크톱 상호작용 펫입니다.

## Characters

- **늑구 (Neukgu)**
- **가디 (Growlithe)**
- **로이스 (Royce)**

각 캐릭터는 걷기, 앉기, 자기, 끌기, 클릭 반응 등의 기본적인 상호작용을 제공합니다.

## Features

- 데스크톱 위 자유 이동
- 캐릭터 자동 행동 및 상태 전환
- 클릭 및 드래그 상호작용
- 이동 방향에 따른 캐릭터 방향 전환
- 캐릭터별 고유 클릭 반응
- 캐릭터별 이스터에그
- Windows Portable EXE 지원

## Easter Eggs

### 가디 (Growlithe)

가디를 클릭한 상태에서

`pocketmon`

을 입력하고 Enter를 누르면 가디 전용 메시지가 출력됩니다.

### 로이스 (Royce)

로이스를 클릭한 상태에서

`royce`

를 입력하고 Enter를 누르면

**"우재민 화이팅!"**

메시지가 출력됩니다.

## Characters

### 늑구 (Neukgu)

기본 데스크톱 펫 캐릭터입니다.

### 가디 (Growlithe)

포켓몬스터의 가디(Growlithe)를 모티브로 한 캐릭터입니다.

### 로이스 (Royce)

검정색과 갈색 털을 가진 강아지를 모티브로 제작한 캐릭터입니다.
