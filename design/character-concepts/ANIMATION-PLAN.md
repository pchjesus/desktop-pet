# 말랑한 데스크탑 강아지 — 후속 애니메이션 계획

`6aa9626`의 해부학적 보행 중심 설계를 사용자 피드백에 맞춰 수정했다.
둥글고 단순한 신체와 작은 움직임이 기준이다. 이 문서와 IDLE/WALK 프리뷰는
승인 전 시안이며 런타임 애니메이션·상태·이동 속도는 교체하지 않는다.

## 표현 원칙

- 점눈, 짧은 주둥이·발, 두꺼운 선과 단순한 면을 유지한다. 다리를 세세한
  관절로 쪼개거나 과장된 무게/근육을 표현하지 않는다.
- 발은 몸 아래에서 짧게 움직이고, 몸은 살짝 통통하며 꼬리는 부드럽게 살랑인다.
  얼굴이 과도하게 늘어나거나 머리·몸통 접합부가 벌어지지 않게 한다.
- 늑구는 가볍고 순하게, 로이스는 조금 느긋하고 든든하게 움직인다.
  차이는 큰 동작보다 귀 모양·눈썹·체형·리듬으로 표현한다.

## 상태별 초안

| 상태 | 늑구 | 로이스 | 전환/확인 기준 |
|---|---|---|---|
| IDLE | 2.4초 작은 통통 호흡, 말린 꼬리 살랑 | 2.8초 느긋한 호흡, 짧은 꼬리 살랑 | 발은 지면 유지. 점눈이 짧게 닫혔다 열리며 표정 보존. 현재 프리뷰는 약 1~2.5% 부풀림. |
| WALK | 0.84초 가벼운 작은 발걸음 | 1초 짧고 편안한 발걸음 | 짧은 발의 앞뒤 이동과 작은 회수, 몸 ±0.6 단위. 머리를 크게 흔들지 않으며 실제 이동과 맞춰 미끄러짐 확인. |
| SIT | 엉덩이를 둥글게 내리고 앞발을 모음 | 넓은 몸이 폭신하게 내려앉고 처진 귀 유지 | 약 250ms 초안. 뒷발은 몸 아래로 숨기고 앞발 기준 유지. 형태 전환 중 얼굴 위치 점프 금지. |
| SLEEP | 몸을 둥글게 모으고 머리를 앞발에 기대기 | 통통한 몸을 낮추고 귀가 얼굴 옆으로 내려옴 | 약 450ms 눕기, 느린 호흡과 닫힌 눈. 깨울 때 눈→머리→몸 순서로 작게 복귀. |
| REACT | 눈·귀가 먼저 반응하고 작은 고개 기울임 | 눈썹과 귀, 짧은 꼬리로 반가움 표현 | 약 300ms 초안. 큰 점프 대신 발을 유지한 작은 반응. 기존 클릭 메시지/로이스 이스터에그 보존. |
| DRAG | 짧은 발을 살짝 모으고 귀가 부드럽게 기울어짐 | 몸이 작게 늘어졌다 돌아오고 발이 모임 | 관절 꺾임·과한 흔들림 금지. 해제 시 약 200ms 부드러운 착지와 정상 복귀. |

시간과 수치는 승인 전 방향이다. SIT/SLEEP/REACT/DRAG는 이번 단계에
구현하지 않았다. 프리뷰 보행은 단순한 발 그룹 이동이며 최종 런타임의
이동 속도·방향 전환과 연결되지 않는다. 네 위상 APNG의 1초 재생을 실제
0.84초/1초 보행 또는 호흡 시간으로 해석하지 않는다.

## 후속 구현의 안전 조건

기존 `setState`, `setFacing`, `render` 계약을 유지하고 표현은 캐릭터 내부에서
처리한다. 바깥 방향 반전과 안쪽 자세 transform을 분리한다. SVG의 `n-`/`r-`
접두사, `core`, `head`, `body`, `tail`, 네 `leg-*`, `eyes-open/closed`를 사용한다.
곡선형 꼬리 회전점은 시안 좌표(96×88)의 늑구 (26,53), 로이스 (24,54)다.
이전 각진 모델의 관절 피벗은 재사용하지 않는다.

DRAG 진입 시 기존 자세 전환을 취소하고 자동 이동을 유지하려 들지 않는다.
해제 시 Main의 실제 위치 동기화 후 착지한다. REACT/정상 상태 전환도 최신
상태에서 시작하며 오래된 완료 콜백이 새 상태를 덮어쓰지 않게 한다.
기존 공통 엔진·입력·우선순위는 불필요하게 바꾸지 않는다.

승인 후 실제 78×72 표시와 모든 자세/전환/양방향을 측정하여 캐릭터별
경계만 필요한 만큼 검토한다. 작은 호흡마다 경계를 재계산하여 창을 흔들지
않는다. 이번 작업의 화면 경계 수정은 그대로 유지한다.

## 승인 후 검증

1. 밝은/어두운 배경과 작은 크기에서 귀·주둥이·점눈·눈썹·발의 가독성을
   사용자 확인한다. Windows DPI 100/125/150%는 실제 기기에서 검증한다.
2. 연속 IDLE/WALK와 네 위상에서 발의 과한 미끄러짐, 다리/몸 틈,
   방향 전환 점프, 부풀림으로 변형된 얼굴이 없는지 확인한다.
3. SIT/수면/클릭/드래그 전환, 연속 입력과 취소·복귀를 검증한다.
4. 네 캐릭터 이동·클릭·드래그·우클릭·화면 경계, 가디 입력·모션,
   Spheal ROLL/CLAP/WATER GUN/ICE BEAM 및 로이스 메시지를 회귀검증한다.
5. `npm run check`, `npm test`와 필요한 집중 테스트를 수행한다.
   Windows Electron/EXE 시각 검증은 현재 **NOT VERIFIED**다.

사용자 승인 전 런타임 교체·전체 애니메이션 적용·EXE 배포·main 병합은 하지 않는다.
