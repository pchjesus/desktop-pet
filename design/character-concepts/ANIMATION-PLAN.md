# 늑구·로이스 애니메이션 후속 구현 계획

이 문서는 시안 승인 후 구현할 설계다. 현재 런타임 SVG, 캐릭터 클래스,
Pet Engine, 입력과 상태 확률은 교체하지 않았다. 시안의 IDLE/WALK는
형태와 접지 리듬을 검토하는 예시이며 최종 관절 애니메이션이 아니다.

## 구조와 좌표 계약

- 기존 `setState`, `setFacing`, `render` 호출 계약을 유지하고 캐릭터 내부에만
  자세 계산을 둔다. 방향 반전은 바깥 그룹, 자세는 안쪽 그룹이 담당하여
  같은 transform을 덮어쓰지 않는다. 창 이동 속도를 시안 때문에 바꾸지 않는다.
- SVG의 `n-` / `r-` 접두사를 유지한다. `body`, `neck`, `head`, `tail`,
  네 `leg-*`, `eyes-open/closed`를 독립 제어한다. 다리는 구현 때
  상부·하부·발 그룹으로 나눠 길이를 고정한다. 새 라이브러리는 필요 없다.
- 시안 좌표(96×88)의 초기 피벗은 아래와 같다. 최종 피벗은 승인된 형상에
  맞춰 확인하고, 현재 런타임 크기(78×72)로 변환한 뒤 접지선을 정한다.

| 부위 | 늑구 (x,y) | 로이스 (x,y) |
|---|---|---|
| 머리/목 | 64,37 | 66,39 |
| 가까운 귀 뿌리 | 66,25 | 64,28 |
| 꼬리 뿌리 | 30,44 | 27,47 |
| 가까운 앞다리 | 65,49 | 67,54 |
| 먼 앞다리 | 58,49 | 58,53 |
| 가까운 뒷다리 | 30,53 | 31,56 |
| 먼 뒷다리 | 32,51 | 31,55 |

## 상태별 동작

| 상태 | 신체 동작 및 접지 | 전환과 캐릭터 차이 |
|---|---|---|
| IDLE | 발은 지면에 고정하고 흉곽·목만 작은 호흡. 눈꺼풀 닫힘/열림을 별도 표현. 귀는 뿌리에서 움직이고 꼬리는 골반 연결을 유지한다. | 늑구 2.4초 호흡, 귀가 먼저 반응하는 경계감. 로이스 2.8초 호흡, 무거운 흉곽과 낮은 꼬리. 눈깜박임은 보행과 독립하되 SLEEP/DRAG 진입 때 취소. |
| WALK | 네 발 접지 순서를 유지한다. 접지 중 발의 화면상 위치를 창 이동량으로 보상하고, 회수 중에만 발을 들어 앞으로 보낸다. 고정된 상·하부 길이와 발 목표로 무릎/비절을 계산하고 골반 하중과 머리 역위상을 더한다. | 초안 주기 늑구 900ms, 로이스 1100ms. 접지율 60%/64%, 다리 위상 0/¼/½/¾. 실제 이동 속도에 보폭을 맞추고 짧은 이동에서도 발이 미끄러지지 않게 한다. 정지 시 가까운 접지 자세로 수렴한 후 IDLE. |
| SIT | 앞발은 고정하고 골반을 낮추며 뒷무릎을 접는다. 몸통 각도와 목을 보상하여 머리가 갑자기 떨어지지 않게 한다. | 240–320ms 전환 초안. 늑구는 세운 목과 정돈된 앞발, 로이스는 넓은 가슴과 바깥으로 조금 벌어진 뒷발. 일어날 때 먼저 하중을 앞발로 이동. |
| SLEEP | SIT에서 앞다리를 접고 가슴을 낮춘 뒤 머리를 발 위에 둔다. 눈은 닫고 낮은 호흡만 유지하며 꼬리를 몸 옆에 둔다. | 눕기 450–650ms, 느린 호흡 3–4초 초안. 클릭 시 눈·귀→머리→앞다리 순으로 깨어나되 기존 반응/상태 결정을 따름. 기존 수면 표시가 있다면 표시 범위도 측정. |
| REACT | 발을 고정한 채 눈·귀가 먼저 반응하고 목/머리가 기울며 어깨가 따라간다. 전체 SVG를 튕기는 대신 하중 이동을 표현한다. | 250–400ms 초안. 늑구는 귀를 세우고 가벼운 고개 반응, 로이스는 눈썹과 넓은 주둥이의 작은 반응. 기존 클릭 메시지와 `royce` 이스터에그를 보존. 완료 시 최신 정상 상태로 복귀. |
| DRAG | 접지 해제 후 몸의 무게중심 아래로 다리가 부드럽게 접히고 목·꼬리는 짧게 지연된다. 과도한 흔들림과 몸 밖으로 빠지는 관절을 금지한다. | 기존 드래그 입력을 최우선 처리. 해제 시 Main의 실제 위치를 동기화한 뒤 발 착지→정상 자세로 180–260ms 복귀. 이전 이동 목표/타이머로 되돌아가지 않게 한다. |

## 중단·시간·경계

DRAG는 진행 중인 자세 전환과 REACT를 취소한다. REACT는 현재 정상 자세에서
시작하며 반복 클릭은 기존 입력 정책을 따른다. 정상 상태 전환은 현재 보간
자세를 시작점으로 사용하고, 취소 토큰으로 이전 완료 콜백이 새 상태를
덮어쓰지 못하게 한다. 숨김/프레임 지연 후에는 누적 시간을 제한하고 현재
상태의 유효 자세를 계산한다. 공통 상태 우선순위를 새로 만들지 않는다.

시안의 보행은 다리 그룹 이동과 고정된 굽힘 형태를 사용한다. 최종 구현에는
위의 관절 분리와 발 목표 계산이 필요하다. `preview.html`의 실제 주기와
`motion-sheet.png`의 네 위상으로 먼저 비교하고, 정규화된 1초 APNG를 실제
속도 검증으로 사용하지 않는다.

승인 후 모든 상태/전환/양방향의 실제 DIP 표시 범위를 측정하여 캐릭터별
body envelope를 갱신한다. 매 프레임의 작은 SVG 호흡으로 이동 경계를
다시 계산하여 창이 흔들리게 하지 않는다. 말풍선은 본체 경계를 키우는
기준으로 쓰지 않는다. 현재 시안을 그대로 런타임에 복사하지 않는다.

## 후속 구현 승인 및 검증 기준

1. 밝은/어두운 배경에서 귀·주둥이·체형을 사용자 승인하고 실제 78×72에서
   눈과 발이 읽히는지 확인한다. Windows 100/125/150% 배율도 확인한다.
2. IDLE 한 주기와 WALK 네 위상·연속 재생으로 접지 중 발 미끄러짐,
   무릎 뒤집힘, 목/골반 틈, 방향 전환 시 점프를 확인한다.
3. SIT↔IDLE, SLEEP↔REACT, 이동 중 클릭, 전 상태에서 DRAG 및 즉시 해제,
   연속 클릭과 취소 후 오래된 콜백의 상태 덮어쓰기를 검증한다.
4. 네 캐릭터 이동·경계·클릭·드래그·우클릭 종료 회귀와 로이스 메시지,
   가디 입력, Spheal ROLL/CLAP/WATER GUN/ICE BEAM을 유지한다.
5. `npm run check`, `npm test`와 필요한 자세/취소 회귀를 실행한다.
   실제 Windows Electron/EXE 시각 승인은 별도이며 현재 **NOT VERIFIED**다.

사용자 승인 전 런타임 교체, 전체 애니메이션 적용, EXE 배포 및 main 병합은
수행하지 않는다. 후속 작업도 캐릭터별 가역 커밋으로 진행한다.
